
#Tic-Tac-Toe Game

A simple Tic-Tac-Toe game made using HTML, CSS, and JavaScript.

--Structure of 3x3 Board created using HTML Table
--Designed using CSS 
--The action of deciding which player has won logic written and done by javascript

##How to play
1. The board has 9 empty boxes.
2. Player 1 puts X in one empty box.
3. Player 2 puts O in another empty box.
4. They continue taking turns.
5. The first player to get 3 of their symbols in a row wins
6. Use the reset button to load the game again

##Features
3 × 3 Tic-Tac-Toe board
Two-player gameplay
Automatic winner detection
Draw detection
Turn switching between X and O
Restart/New Game option
Alert message for game result

##How to run

Method 1 — Directly in browser

Open your project folder.
Double-click index.html.
It will open in Chrome/Edge.
Play the game. 

Method 2 — VS Code

If you're using VS Code:

Open the tic-tac-toe folder.
Open index.html.
Right-click the file.
Choose Open with Live Server if you have the Live Server extension.
Your game opens in the browser.
